# Fini

Fini 是一门处于实验阶段的极简编程语言。目标是语法简单、无需手动管理内存，并由编译器分析和安排内存释放，不依赖 GC。

v0 聚焦整数、布尔值、局部变量、表达式和具名函数。循环、递归与复合数据留到后续阶段。

## 实现

当前仓库保留设计文档，尚无可运行实现。计划使用 Go 编写转换工具，路线为 Fini 源码 → 名称与类型检查 → Go 源码 → `go build` → 可执行程序。程序从无参数的 `main` 开始，正常返回后自动打印结果。

实现将从一个返回整数的最小程序开始，逐步加入运算、变量、条件和函数调用。词法细节随实验补齐，不作为开始实现的前提。

Go 原型用于验证语言行为和构建流程；无 GC 的动态内存释放方案仍需单独研究。
