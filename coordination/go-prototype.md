# Go 转换原型

## 当前状态

上一轮生成的实现、测试和示例已撤除，保留语言规范与研究文档。接下来由用户手写代码，Agent 负责讨论、审阅和校验，按 `AGENTS.md` 的实现协作约定执行。

## 目标

用可运行的程序检验 v0 语义。首个目标只覆盖以下程序：

```text
fn main() -> Int {
    1
}
```

完成读取、解析、最小规则检查、Go 代码生成与构建，运行后输出 `1`。这是部分语义的实验，不代表已实现整个 v0。

## 实施顺序

1. 建立 Go 工程和读取源码的命令入口，确认能读到文件内容。
2. 识别上述程序的词法单位并保留行列位置，确认名称、数字和符号被正确划分。
3. 解析函数声明和整数结果，确认结构识别正确，错误写法能被拒绝。
4. 检查入口、参数、结果类型与字面量范围，从解析出的结构生成 Go，构建并执行，确认输出 `1`。
5. 逐项加入运算、局部变量、条件和函数调用；每项同时补对应检查与正反例，不等所有模块完成后才执行程序。

不增加复合数据、循环、递归或内存释放机制。生成程序依赖 Go 运行时，不作为无 GC 目标的验证。

## 词法候选

以下是上一轮原型采用过的临时规则，可作为手写实现的参考，不提升为稳定语言规范，也不要求在首个实验中全部支持：

- 源码使用 UTF-8；名称使用 Unicode 字母、十进制数字和下划线，首字符不能是数字。名称按原始字符区分，不做规范化。
- 保留 `fn`、`let`、`if`、`else`、`true`、`false`、`Int`、`Bool`。
- 整数仅使用 ASCII 十进制数字，允许前导零；不支持其他进制或数字分隔符。
- 负号后允许空格，支持连续取负及额外分组括号。负号直接作用于数字时按有符号字面量检查范围。
- `else` 可以与前一个右大括号同一行，也可以另起一行；允许空行与纯注释行。
- 函数参数和实参可以跨行，允许尾随逗号；圆括号内的分支块仍保留定义行分隔。
- 诊断输出到标准错误；转换或运行错误退出状态为 1，命令用法错误为 2。这些状态不承载 Fini 的计算结果。

## 验证范围

- 正常计算、布尔值、中文名称、跨行运算、分支局部变量及函数返回。
- 名称冲突、未绑定名称、类型错误、参数数量、缺失入口及递归。
- 整数字面量边界、四种整数运算的越界、未执行分支和未使用实参。
- 生成源码经 Go 工具链构建并执行，检查标准输出与错误输出。

当前没有可执行实现或测试，不能沿用上一轮原型的通过结果。手写实现需要重新验证以上行为；标量测试通过仍不能证明动态数据的静态释放。
