# v0 设计取舍

v0 以固定大小的值和有限计算研究表达式组合与函数抽象。本笔记解释模型的理由与代价；语言行为见 [语义](../spec/v0.md)，源码写法见 [语法](../spec/syntax-v0.md)。

## 最小模型

| 设计 | 理由 | 代价 |
| --- | --- | --- |
| 单一有符号 64 位整数 | 表示大小固定，不需要数值类型提升规则 | 数值范围有限，运算需要越界检查 |
| 独立布尔值 | 条件必须明确产生真假，不需要整数到布尔值的转换 | 判断必须使用比较或布尔值 |
| 不可重新赋值的变量与参数 | 后续读取含义稳定，无需跟踪名称被覆盖后的变化 | 更新计算结果需要另一个名称 |
| 禁止重复名称与隐藏外层名称 | 同一个可见局部名称对应唯一的定义 | 内层变量有时需要换名 |
| 顶层具名函数直接调用 | 调用目标静态明确，无需保存函数环境 | 函数不能作为值传递 |
| 调用关系无环 | 函数可以按依赖顺序分析 | 不支持循环和递归 |
| 操作数和实参从左到右求值 | 一条固定的执行顺序，无需延迟计算机制 | 未使用的实参也会计算或出错 |
| 条件只执行选中分支 | 避免不需要的计算，便于分路径分析 | 汇合后的结果仍需保持有效 |
| 变量用换行分隔，块末表达式作为结果 | 支持给中间结果命名，保持输入和输出明确 | 不支持分号；解析需要区分括号内续行和块内定义 |
| 二元运算显式括号 | 不需要默认优先级，计算结构直接可见 | 嵌套运算的括号较多 |

## 越界处理

固定大小不意味着采用机器算术的回绕结果。v0 运算越界时终止计算并报错，避免悄悄改变数学结果；不提供捕获或恢复机制。

静态检查未执行分支，不等于提前执行分支：

```text
if true { 1 } else { (9223372036854775807 + 1) }
```

结果为 1。未选中的分支接受名称和类型检查，但加法不执行。超范围字面量则在编译时拒绝，即使它位于未执行分支。

## 内存局限

固定范围整数和布尔值可以直接存储，不必为了数值增长或函数环境增加动态存储。这使 v0 适合验证求值规则，却几乎无法验证动态回收。

动态数据阶段需要大小可随输入变化的值，以及名称复用、函数返回和分支汇合的例子。相关反例见 [基础构造与内存释放](01-foundations.md)。
