# Fini v0 语言参考

Fini v0 是用于研究语言基础构造的最小模型。本文档描述语言行为；生成 Go 的实验原型与动态内存释放算法尚未实现。

## 目录

- [语法](syntax-v0.md)：注释、字面量、函数、变量、代码块、条件和运算。
- [语义](v0.md)：程序结构、类型、作用域、求值和错误。

`else` 的换行位置、名称的完整字符分类与字面量格式等规则仍有缺口，见 [设计问题](../questions/01-language-design.md)。

## 语言范围

| 项目 | v0 |
| --- | --- |
| 值 | 有符号 64 位整数 `Int`、布尔值 `Bool` |
| 运算 | 加、减、乘、取负、相等比较、小于比较 |
| 名称 | 不可重新赋值的局部变量与参数 |
| 定义 | `let 名称 = 表达式`，按行定义 |
| 排版 | 定义用换行分隔，不支持分号；圆括号内允许跨行 |
| 名称字符 | 支持中文等文字、数字和下划线，不能以数字开头 |
| 入口 | 无参数的 `main`，返回 `Int` 或 `Bool` |
| 结果 | 正常返回后自动打印一次 |
| 组合 | 嵌套表达式、代码块、条件分支 |
| 抽象 | 顶层具名函数的直接调用 |
| 检查 | 执行前检查名称、类型、字面量范围与调用关系 |
| 求值 | 操作数和实参从左到右求值，条件只执行选中分支 |

v0 不支持循环、递归、复合数据、函数值、局部函数、环境捕获、隐式类型转换或手动内存操作。

## 内存目标

Fini 的目标是由编译器静态安排释放操作，在程序运行时执行。使用者无需管理所有权或生命周期。释放分析应保证仍需使用的存储有效，并回收不再需要的动态存储；不要求全局最早释放或最低峰值内存。

v0 只有固定大小的标量，不能据此验证动态数据的无 GC 方案。相关分析见 [内存研究](../notes/01-foundations.md#5-编译期内存释放)。

## 原型实现

```text
Fini 源码
    ↓ 转换工具：解析，检查名称、类型和调用关系
Go 源码
    ↓ go build
可执行程序
```

计划使用 Go 编写转换工具，必须实现 Fini 的规则，包括整数越界检查、名称冲突检查和求值顺序，不能直接采用 Go 的默认行为。

生成的程序调用 Fini 的 `main`，正常返回后自动打印结果。输出格式见 [程序结果](v0.md#程序结果)；这属于原型运行接口，不新增语言内置打印函数。

Go 原型依赖包含 GC 的 Go 运行时，用于验证语义和构建流程，不作为 Fini 最终的内存释放实现。参见 [Go GC 指南](https://go.dev/doc/gc-guide)。
