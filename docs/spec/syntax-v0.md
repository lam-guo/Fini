# 语法

本文描述 Fini v0 的源码写法。`else` 的换行位置与部分词法规则尚未定义，相关问题见 [设计问题](../questions/01-language-design.md)。执行行为见 [语义](v0.md)。单独展示的表达式和函数是代码片段，完整程序必须包含 `main`。

## 名称

变量名、参数名与函数名可以包含字母、中文等文字、数字和下划线。首字符必须是文字或下划线，不能是数字；空格及运算符等符号不属于名称。

例如 `count`、`数量`、`数量1`、`_result` 可以作为名称，`1count` 不合法。完整字符分类、保留字及名称比较的规则仍需补齐。

## 换行

变量定义之间、变量定义与块末结果之间，使用换行分隔；初始化表达式必须完整结束，才能开始下一项。v0 不支持以分号分隔定义。

运算、函数调用和参数表的圆括号内允许跨行，内部换行不结束表达式。若圆括号中嵌套条件分支块，分支块内部仍按行分隔定义。

```text
fn main() -> Int {
    let 数量 = (2 +
        3)
    数量
}
```

上例输出 `5`。代码块自身用大括号划定范围，换行与缩进不创建作用域。条件分支块的跨行结构见后文；`else` 是否可以另起一行仍未定义。

## 注释

`//` 开始行注释，内容延续到行末或文件结束。注释可以单独占行，也可以跟在代码后。

```text
// 计算平方
fn square(x: Int) -> Int {
    (x * x) // 块的结果
}
```

v0 不支持 `/* ... */` 块注释。

## 字面量

整数示例为 `0`、`3`、`-3`；布尔值写作 `true`、`false`。整数必须位于 `Int` 的范围内，见 [类型与运算](v0.md#类型与运算)。

`-9223372036854775808` 是合法的负整数字面量；正字面量 `9223372036854775808` 超出范围。进制、数字分隔符与负号间距等词法细节尚未定义。

## 函数

函数使用 `fn` 声明。参数名后用冒号标注类型，箭头后标注结果类型；函数体放在大括号内。

```text
fn square(x: Int) -> Int {
    (x * x)
}
```

调用使用函数名和圆括号内的实参：`square(3)`。多个参数或实参之间用逗号分隔。

## 程序入口

顶层只包含函数定义，必须有一个无参数的 `main` 函数。`main` 的结果类型为 `Int` 或 `Bool`。

```text
fn square(x: Int) -> Int {
    (x * x)
}

fn main() -> Int {
    square(3)
}
```

程序从 `main` 开始，正常返回后自动打印结果。上例输出 `9`。

## 变量

变量使用 `let 名称 = 表达式` 按行定义，初始化表达式产生变量的值：

```text
fn calculation() -> Int {
    let x = 2
    let y = (x + 3)
    (y * y)
}
```

结果为 25。变量从定义之后到所在块结束可见，不可重新赋值。名称冲突规则见 [名称与作用域](v0.md#名称与作用域)。

## 代码块

代码块用 `{ }` 包围，由零个或多个变量定义及最后一个表达式组成。定义依次执行，最后一个表达式产生块的结果。

函数体和条件分支使用同样的代码块结构。v0 不支持空块、任意表达式语句或提前 `return`；定义使用换行分隔，缩进不决定作用域。

## 条件

`if` 后写条件，大括号内写选中时的计算，`else` 后写另一分支。

```text
fn abs(n: Int) -> Int {
    if (n < 0) {
        -n
    } else {
        n
    }
}
```

两个分支都必须存在，并产生相同类型的结果。分支可以先定义局部变量，名称不进入另一分支或块外。

上例中的圆括号属于比较运算；条件本身不必额外套括号，例如 `if true { 1 } else { 2 }`。`else` 是否可以另起一行尚未定义。

## 运算

每个二元运算都写成 `(左表达式 运算符 右表达式)`，不使用省略括号的优先级写法。

```text
(2 + (3 * 4))
((2 + 3) * 4)
```

结果分别为 14 和 20。`2 + 3 * 4` 与 `x + y` 不符合 v0 的写法。二元运算符为 `+`、`-`、`*`、`==`、`<`。

一元取负支持 `-x` 和 `-(x + 1)`。取负无需写成二元减法；操作数必须为 `Int`，最小整数取负产生运行时越界错误。普通分组括号、连续负号和负号间距尚未定义。
